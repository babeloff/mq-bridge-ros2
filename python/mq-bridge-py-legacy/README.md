# mq-bridge-py (renamed)

This package is now published as [`mq-bridge`](https://pypi.org/project/mq-bridge/).

```bash
pip install mq-bridge
```

The import path is unchanged: `import mq_bridge`. This last `mq-bridge-py` release is empty
and only depends on `mq-bridge`, so existing installs keep working. It receives no further
updates.
